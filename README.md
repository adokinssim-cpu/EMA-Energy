
# EMA Energy Management

Application Flutter développée dans le cadre de la certification **10 000 Codeurs** (Track : **Full Stack Development**).

## 🌍 Présentation
EMA (Énergie, Marketing, Automatisation) est une plateforme numérique innovante conçue pour moderniser la gestion des systèmes énergétiques. Cette application permet aux utilisateurs de gérer efficacement leurs installations, de suivre leurs données et d'automatiser des processus techniques complexes.

## 🚀 Fonctionnalités principales
- **Gestion d'installations** : Consultation et suivi des équipements énergétiques.
- **Navigation moderne** : Utilisation de **GoRouter** pour une expérience fluide.
- **Expérience utilisateur** : Support du mode clair et du mode sombre.
- **Formulaire de saisie** : Interface intuitive pour la création et la modification de données.
- **Réactivité** : Design responsive adapté aux smartphones et tablettes.

## 🛠️ Stack Technique
- **Framework** : Flutter (Dart)
- **Architecture** : Clean Code / Modulaire
- **Navigation** : GoRouter
- **Gestion d'état** : ValueNotifier
- **Outils** : VS Code, Git/GitHub, Android SDK

## 📁 Structure du projet
- `/lib` : Code source principal
  - `/models` : Modèles de données
  - `/screens` : Écrans de l'application
  - `/widgets` : Composants réutilisables
- `/android` / `/ios` / `/web` : Configurations spécifiques aux plateformes
